## Description

The Restaurant Ordering System is a Java console application that allows users to view a restaurant menu, create customer orders, add and remove items, calculate order totals, and update order statuses.

## Features

- Display all menu items.
- Create new customer orders.
- Add menu items to an order.
- Remove items from an order.
- View order details and totals.
- Calculate subtotal, 8.25% tax, and final total.
- Update order status.
- Validate user input.

## Technologies

- Java
- Visual Studio Code
- Git and GitHub

## Project Structure

- `src/restaurant/model` – Menu items, menus, orders, and order status.
- `src/restaurant/service` – Restaurant operations and price calculations.
- `src/restaurant/console` – Console interface and main application.

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `src/restaurant/console/Main.java`.
3. Run the `main` method.
4. Follow the instructions displayed in the terminal.
